## این ربات چه کار می‌کند؟

فرض کنید یک فروشگاه لباس یا یک شرکت مهاجرتی دارید و مشتری‌ها مدام در تلگرام
سوال‌های تکراری می‌پرسند: «قیمت چنده؟»، «چه رنگ‌هایی دارید؟»، «آدرستون کجاست؟»
**منشیار** به‌صورت خودکار و با لحنی یکدست جوابشان را می‌دهد — حتی اگر سوال را
جور دیگری بنویسند.

## ✨ ویژگی‌ها

- 🧠 **تطبیق هوشمند سوال** — ترکیب کلیدواژه و جست‌وجوی فازی؛ غلط املایی و جمله‌بندی متفاوت را می‌فهمد
- 📝 **لحن یکدست و حرفه‌ای** — همه پاسخ‌ها با قوانین نگارشی شما: بدون علائم نگارشی، بدون واژه انگلیسی، بدون شماره‌گذاری، تک‌خط، بدون ایموجی (تک‌تک قابل تنظیم)
- 📂 **فایل دانش ساده** — فقط یک فایل `knowledge.json` را با سوال‌وجواب‌های کسب‌وکارتان پر کنید؛ بدون دیتابیس پیچیده
- 🖥️ **پنل ترمینال** — تست پاسخ‌ها و مدیریت رکوردها از خط فرمان
- 🚀 **نصب در ۵ دقیقه** — فقط پایتون لازم دارد
- 🆓 **رایگان و متن‌باز** — تحت لایسنس MIT

## 🚀 شروع سریع (۵ دقیقه)

**۱. ساخت ربات و گرفتن توکن**

در تلگرام به `@BotFather` پیام بدهید، دستور `/newbot` را بفرستید و توکن را کپی کنید.

**۲. نصب**

```bash
git clone https://github.com/thelilcapi/monshiyar.git
cd monshiyar
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

توکن را داخل فایل `.env` بگذارید:

```
BOT_TOKEN=توکن_ربات_شما
```

**۳. پر کردن فایل دانش**

فایل `knowledge.json` را با اطلاعات کسب‌وکارتان پر کنید:

```json
{
  "id": "shirt-colors",
  "question": "پیراهن چه رنگ‌هایی دارد",
  "keywords": ["پیراهن", "رنگ", "رنگبندی"],
  "answer": "پیراهن‌های مردانه ما در رنگ‌های قرمز آبی سرمه‌ای سفید و مشکی موجود است"
}
```

**۴. اجرا**

```bash
bash run.sh
```

تمام شد! در تلگرام به ربات‌تان پیام بدهید و تست کنید. 🎉

## 🖥️ پنل ترمینال

```bash
python3 cli.py
```

| دستور | کار |
|---|---|
| `test <سوال>` | شبیه‌سازی پاسخ ربات بدون نیاز به تلگرام |
| `list` | نمایش همه رکوردهای فایل دانش |
| `help` | راهنما |

## ⚙️ ساختار پروژه

```
monshiyar/
├── bot.py              نقطه ورود ربات تلگرام
├── cli.py              پنل ساده ترمینال
├── core/
│   ├── config.py       بارگذاری تنظیمات
│   ├── knowledge.py    مدیریت فایل دانش
│   ├── matcher.py      تطبیق هوشمند (کلیدواژه + فازی)
│   └── sanitizer.py    موتور قوانین نگارشی پاسخ‌ها
├── knowledge.json      فایل دانش (نمونه: فروشگاه لباس)
├── config.yaml         تنظیمات
└── requirements.txt
```
